# OCR开关与拍照验收

## 使用方法

安装 `releases/app-v1.0.10+12.apk`，打开“我的”，在顶部找到 **OCR图片识别** 开关。默认开启；关闭后重启、切本地或已连接的店铺都保持关闭，业务备份不会覆盖该设备设置。

关闭OCR仍可扫码快递号、拍照、从相册保存、确认入库及手工填写商品。只有照片和单号的新单显示待补录，不自动增加商品库存；原有照片、商品和库存保留。重新开启只恢复以前未完成的自动识别任务，关闭期间新拍的单据需主动重新识别或手工补录。

图片重识别和图像AI受同一开关控制，关闭时不会悄悄启动本机OCR或图片远程识别。纯文本AI仍遵循原有联网配置；完全本地模式继续禁止远程请求。

## 拍照变化

- 普通和极速拍照均去掉整屏闪白与闪烁动画，改为照片真实保存后一次轻触觉、快门局部勾及“已拍好，可以移开”。手机系统可能禁用触觉，文字/图标仍可反馈。
- 按快门仅显示拍摄中；失败不提示成功。照片保存后才可移开，“已录入”还要求单据成功保存。
- 普通相机保存原图后直接交回页面，裁剪/方向校正和识别移至后续处理；OCR关闭时直接保留原照片，不做额外整图处理。
- 拍摄页期间暂停启动新的后台裁剪/OCR，已运行一项安全结束；退出拍摄后继续。这样避免后台队列持续与连续拍摄争用资源。
- Android支持且非低内存设备尝试零快门延迟模式，不支持或绑定失败则同画质回退；保留正式静态照片质量，不以低清预览截图替代。

## 建议验收

1. 先关闭OCR，连续录入20个不同快递号并查看照片；重启和切店后检查开关仍关闭、单号与照片对应、待补录及手工补商品正常。
2. 开启OCR，进入极速页面连续拍摄；页面内显示退出拍摄后识别，退出后旧pending继续处理，关闭期间拍的新单不自动补跑。
3. 普通拍照关闭OCR后重新开启再确认，仍需显示待补录，不能凭开关变化声称图片已识别。
4. 对比旧版和新版相同手机、光照、距离与单据，分别记录普通/极速各至少20次延迟及失败；暗光、补光和成功提示后立即移动样张单列检查文字清晰度与方向。
5. 拍摄或识别中取消、系统返回、切后台再恢复，确认无提前成功、无旧图覆盖新单、原图仍可查。实际速度、模糊和内存均以真机结果为准。

## 当前限制

本轮未连接Android真机，不能声称已达到系统相机速度，设备兼容、真实延迟和清晰度仍待上述验收。APK沿用项目现有本地调试证书，供本地验收；没有远程部署或iOS验证。OCR模型资源仍随包保留，关闭开关减少运行时识别，不会缩小安装包体积，也不承诺正在运行的原生推理立即中止或瞬时零内存。
