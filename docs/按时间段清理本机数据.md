# 按时间段清理本机数据

在手机的「数据管理」中打开「按时间段清理本机数据」，按本机时区选择开始和结束时间，范围包含起止分钟。

本功能清理该时间段内的**已结算入库记录**及其关联副本，不清理未结算入库、出库、商品和当前库存。预览展示实际可清理数量、关联图片和跳过原因；先确认范围，再进行第二次不可恢复确认，才开始执行。取消任一次确认都不会删除。

这是物理删除本机数据库中的记录和不再被引用的本机图片，不是隐藏。服务器和其他手机的数据保留；正常同步不会重新下载已清理的记录，「恢复隐藏」也不能恢复它们。本机仅保留阻止重新下载所必需的记录标识。

尚未同步、存在同步冲突、照片或识别仍在处理的记录会跳过，避免删除唯一副本。与其他记录共用的图片会保留；如果文件暂时无法回收，结果会显示待回收数量，后续打开数据库时重试。

请先核对预览范围。清理不会自动删除此前导出的备份文件，也不承诺存储介质取证级安全擦除。开发验证只使用隔离测试库，未清理实际业务数据。
